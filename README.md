# Controle de Estoque - Perfumaria

Projeto frontend desenvolvido em Angular para gerenciamento de estoque de uma perfumaria.

## Funcionalidades

- Login
- Listagem de produtos
- Cadastro de produtos
- Edição de produtos
- Exclusão de produtos
- CRUD mockado com localStorage
- Roteamento com rotas filhas
- Interface com Material Design Bootstrap

## Executando o projeto

Instale as dependências:

npm install

Inicie a aplicação:

npm start

A aplicação estará disponível em:

http://localhost:4200
